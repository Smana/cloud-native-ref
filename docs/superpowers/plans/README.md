# Plans

Each plan records what was true on the date in its filename. Once its work merges it is **not**
updated when the repository moves around it — a 2026-08 plan citing a 2026-09 path would be a
retcon a reviewer could not distinguish from a real edit.

A `scripts/` path in a plan dated before 2026-09-17 predates that day's restructure. For current
locations see [`scripts/README.md`](../../../scripts/README.md).

An AI path in a plan dated before 2026-10-16 — the manifests under
[`ai_paths`](../../../scripts/ci/flux-schema/ai-boundary.yaml), `docs/runbooks/agent-factory/`,
`website/content/docs/platform/ai-platform/` — now lives in
[Smana/ai-native-ref](https://github.com/Smana/ai-native-ref) with the AI specs and plans (ADR-0057).
