{{- /* Renders one group of website/data/stack.yaml as a table with project logos. This is a Role column, not a version column: a hand-maintained version number rots the moment Renovate merges the next bump, and nothing fails when it does. A role — what the component actually does in this platform — does not go stale the same way, so it is what this table states instead. Three behaviours are deliberate: - A group carrying `pin_note` drops the per-row "Pinned in" column entirely and states the shared pin once, above the table. Every CLI tool is pinned in mise.toml, and eleven identical cells carry no information. - An item with no `logo` renders a typographic tile. A missing logo must never fail a build that is otherwise correct, and a table with holes in it reads as broken where a tile reads as intentional. - An item with `logo_dark` emits BOTH marks and lets CSS pick one. The swap is scoped to `.cnref-has-dark` so that the common case — one mark, legible on both grounds — is never hidden by it. Logos are decorative: the component name sits beside every one as linked text, so each carries alt="" and aria-hidden, and a screen reader is not read the same name twice. A group's `decisions` list — ADRs relevant to the whole group, not any one row — renders as a line under `pin_note` (or on its own, if the group has no `pin_note`) rather than repeated per item. Each entry is `{id, title}`: `id` is the ADR's filename stem under content/docs/decisions/ (its leading four digits double as the "ADR-NNNN" label, so no separate number field is needed), and `title` is a short parenthetical, not the ADR's full title — "Cilium", not "Use Cilium instead of the AWS VPC CNI". @param group the `id` of the group to render. */ -}} {{- $id := .Get "group" -}} {{- $group := "" -}} {{- range site.Data.stack.groups -}} {{- if eq .id $id }}{{ $group = . }}{{ end -}} {{- end -}} {{- if not $group -}} {{- errorf "stack-table: no group with id %q in data/stack.yaml" $id -}} {{- end -}} {{- $hasPinColumn := not $group.pin_note -}} {{- with $group.pin_note }}
